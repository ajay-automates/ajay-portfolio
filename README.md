## Why This Exists

A portfolio that reflects what I build — AI-powered systems, automation pipelines, and developer tools. Built with Next.js for fast loading, SEO optimization, and a modern developer experience.

---

## Features

| Feature | Description |
|---------|-------------|
| **Project Showcase** | Interactive cards for each AI/automation project |
| **Responsive Design** | Mobile-first layout with Tailwind CSS |
| **Dark Theme** | Clean, modern aesthetic |
| **Fast Loading** | Next.js SSR + static optimization |
| **Resume Download** | One-click PDF resume access |

---

## Quick Start

```bash
git clone https://github.com/ajay-automates/ajay-portfolio.git
cd ajay-portfolio
npm install
npm run dev
# Open http://localhost:3000
```

## Project Structure

```
ajay-portfolio/
├── components/          # Reusable UI components
├── data/                # Project data and content
├── hooks/               # Custom React hooks
├── pages/               # Next.js pages and API routes
├── public/              # Static assets and images
├── styles/              # Global styles and Tailwind config
├── next.config.js       # Next.js configuration
├── tailwind.config.js   # Tailwind customization
└── package.json
```
